# Everyday A–Z artwork

26 original illustrations generated with the built-in image generation tool for Jonah’s app. Final PNG files are copied intact from the generated originals. No emoji, stock clipart or external hotlinks are used by this chart.

Each filename is paired with a letter in `everyday-alphabet.js`. Q uses qu in quilt; X uses the final /ks/ in box. O uses octopus for the short vowel, avoiding the r-influenced vowel in orange in American English.

## Prompt set

Use case: illustration-story. Asset type: one square vocabulary picture for a kindergarten A–Z tablet app. Make an original, polished children's picture-book illustration, softly hand-painted gouache with subtle paper texture, appealing rich colors, simple readable silhouette and gentle dimensional shading. Isolated single subject centered on a clean white background, generous empty margin all around, fits a square crop. No emoji style, no flat stock icons, no border, no letters, no numbers, no text, no labels, no watermark, no extra decorative props.
