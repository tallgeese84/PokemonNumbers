# Home artwork · v80

Created using the built-in image-generation tool, with transparent backgrounds. These project copies preserve the original generated PNGs and alpha channel; CSS sizes them for the activity cards.

- `fox-v80.png`: friendly original baby fox for the existing Fox destination.
- `games-v80.png`: wooden number blocks and a picture book for Games.
- The Pokémon button and A–Z poster preview reuse the actual Pokémon images in `../sound-buddies/`; see that folder’s manifest for attribution. No generated Pokémon substitutions.

## Fox prompt

Use case: stylized-concept. Asset type: a single navigation illustration for a calm Pokémon-themed learning app for a five-year-old. Create one adorable original baby red fox, full body, seated in a three-quarter view looking warmly toward the viewer, large expressive dark brown eyes with bright highlights, soft orange fur, cream cheeks and chest, two large upright ears, and an oversized fluffy curled tail with a cream tip. Round soft proportions, premium children's picture-book meets softly rendered 3D toy, lightly painterly fur, warm friendly expression, sophisticated clean silhouette readable at 80 pixels. Center the fox with generous clear padding, no cropping. Soft diffuse lighting and a tiny subtle contact shadow. True transparent background. No text, no border, no badge, no landscape, no extra objects, no emoji appearance.

## Games prompt

Use case: stylized-concept. Asset type: one navigation illustration for the Games button in a calm learning app for a five-year-old. A compact charming arrangement of three softly rounded wooden learning blocks with large clean digits '1', '2', and '3', beside a small open picture book with cream pages. Playful inviting composition, one group isolated on a truly transparent background, no landscape. Pastel teal, warm golden yellow, and muted coral block colors. Premium children's picture-book meets softly rendered 3D toy style, smooth tactile wood, soft diffuse light, subtle contact shadow. Big clear shapes that remain legible at 80 pixels; front three-quarter view, generous padding, all objects fully in frame. The digits must be 1, 2, 3, no other text, no letters, no logos, no emoji appearance, no confetti, no border.
